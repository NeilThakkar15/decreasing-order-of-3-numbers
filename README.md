# decreasing-order-of-3-numbers

> A lightweight C program that takes three integers as input and sorts them in decreasing order strictly using nested conditional logic.

This project demonstrates an understanding of fundamental control flow in C, specifically bypassing arrays or built-in sorting algorithms to manually map out logical permutations using `if-else` structures and logical `AND` (`&&`) operators.

## ✨ Features

*   **Raw Logical Sorting:** Compares and sorts three distinct integer values sequentially.
*   **Nested Conditional Flow:** Uses deeply nested `if-else` blocks to evaluate all possible size combinations.
*   **Efficient Evaluation:** Uses logical `&&` to quickly determine the absolute maximum value before parsing the remaining numbers.

## 🚀 How to Run

**Option 1: Using a Local Compiler (GCC)**
1. Clone this repository to your local machine.
2. Open your terminal and navigate to the project folder.
3. Compile the C file:
   `gcc main.c -o number_sorter`
4. Run the executable:
   `./number_sorter`

**Option 2: Using an Online Compiler**
Simply copy the code from `main.c` and paste it into an online C compiler like [Programiz](https://www.programiz.com/c-programming/online-compiler/) to run it instantly in your browser.

## 🧠 Key Learnings

Building this script reinforced key programming fundamentals:
*   Mapping out exhaustive logical permutations.
*   Structuring clean, readable nested conditional blocks.
*   Understanding the behavior of multiple logical operators (`&&`, `>`, `<`) in a single statement.
